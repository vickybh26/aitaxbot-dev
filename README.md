# AiTaxBot — AI-Powered Tax Assistant for India

> Making Indian tax filing simple, affordable, and accessible for everyone.
>
> ## What is AiTaxBot?
>
> AiTaxBot is a free, open-source AI-powered tax assistant designed specifically for the Indian tax system. It helps individuals, freelancers, and small business owners navigate income tax, GST, TDS, and more — without needing to hire a Chartered Accountant (CA).
>
> Built entirely using **Claude Cowork** by a solo non-coder founder, AiTaxBot is a real-world example of what AI-assisted development can achieve.
>
> ## The Problem
>
> Millions of Indians struggle with tax compliance every year:
> - Complex and constantly changing tax laws (Income Tax, GST, TDS)
> - - CA fees that are out of reach for individuals and small businesses
>   - - No simple, reliable, free tool built for the Indian tax context
>    
>     - ## What AiTaxBot Does
>    
>     - - **Tax Calculators** — Income tax, GST, TDS, trading tax, and more (updated for FY 2026-27 / AY 2027-28)
>       - - **AI Chat Assistant** — Ask tax questions in plain language and get clear answers
>         - - **CA Directory** — Find and connect with verified Chartered Accountants
>           - - **Tax Audit Support** — Tools to help with audit preparation
>             - - **Lead Capture & Admin Panel** — For CAs to manage client inquiries
>              
>               - ## Tech Stack
>              
>               - - **Frontend:** TypeScript / React (Vite)
>                 - - **Backend:** Python
>                   - - **Database:** Firebase / Firestore
>                     - - **Infrastructure:** Docker, Railway, Nixpacks
>                       - - **AI:** Built with Claude (Anthropic)

>                                
>                                 - ## Getting Started
>
> ```bash
> # Clone the repo
> git clone https://github.com/vickybh26/aitaxbot-dev.git
>
> # Install dependencies
> npm install
>
> # Copy environment variables
> cp .env.example .env
>
> # Start development server
> npm run dev
> ```
